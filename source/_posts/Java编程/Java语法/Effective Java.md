### Chapter-5  Generics

1. 语法糖

    Java 引入泛型的核心目标：**用编译期检查替代运行时强制转换错误**。
   乍一看，像其他语言的泛型一样，但其实底层是通过编译器自动插入cast语句实现的【类型擦除】。

2. 从api设计的原则理解泛型的设计。
   List<String>对象不可传给List<Object>参数，若允许，则破坏了原对象的声明本意【只存储String对象】。

3. 里氏替换原则在泛型中的体现
   有界通配符的使用：消费者方法的泛型参数使用extends，生产者方法的泛型参数使用super声明

4. 为何Java禁止泛型与数组的混用


   泛型的类型擦除会干扰数组的类型检查【运行期】
   数组的协变特性，遇上泛型的类型擦除，导致错误难以发现【在运行时读取元素才暴漏问题】。

   > 数组的协变：包含元素的具体类型信息，可以在运行时保存新元素时检查类型是否正确。
   > 泛型：是在编译时检查保证元素类型的正确。
